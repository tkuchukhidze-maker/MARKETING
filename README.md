# სახლში Studio — სოც. მედია გუნდის CRM

სამუშაო სივრცე **ბათუმის სახლში** და **ქუთაისის სახლში**-ს სოც. მედია გუნდისთვის.

## რა შეუძლია

- **დაფა თითო სახლზე ცალკე** — ზემოთ მოკლე სურათი (დასადასტურებელი, განსათავსებელი — დღეს / დაგვიანებული, პროცესშია, ამ კვირაში განთავსდა, ვადაგადაცილებული), ქვემოთ მთელი პროცესი სვეტებად: **გასაკეთებელი → მუშავდება (შესწორებითაც) → დასადასტურებელი → განსათავსებელი → განთავსდა** (ბოლო 14 დღე, პოსტის ბმულით და ვინ დადო). დადასტურება / შესწორება და „განთავსდა“ თითო ქსელზე პირდაპირ ბარათიდან. „სია“ ხედი — ძველი ცხრილი სტატუსებით. ფილტრი **Facebook / Instagram / Story**, ძიება, „ჩემი დავალებები“.
- **დადასტურება** — ვიზუალის ატვირთვა ქმნის ახალ ვერსიას (v1, v2…) და დავალებას ავტომატურად გზავნის „დასადასტურებელში“. დადასტურება / შესწორების მოთხოვნა მხოლოდ **ადმინს** და **მარკეტინგის ხელმძღვანელს** შეუძლია.
- **კალენდარი თითო სახლზე** — კვირის ბადე, თითო პლატფორმა თავის რიგში.
- **გუნდი და დატვირთვა** — ვის რამდენი ღია დავალება აქვს თითო სახლში, ვადაგადაცილებული, როლების მართვა (ადმინი).
- **კონტაქტები (CRM)** — შემსრულებლები, ინფლუენსერები, მომწოდებლები, პარტნიორები.
- **ჭკვიანი შეხსენებები** — გამოითვლება ბაზიდან წესებით: ვადაგადაცილება, დასადასტურებელი ვადასთან ახლოს, შემსრულებლის გარეშე დავალება, გადატვირთული წევრი (5+ ღია), ცარიელი დღეები პლატფორმაზე.
- ისტორია და კომენტარები თითო დავალებაზე.

## გაშვება ლოკალურად

```bash
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed
php artisan serve
```

შესვლა: `.env`-ში მითითებული `ADMIN_EMAIL` / `ADMIN_PASSWORD` (ნაგულისხმევად `admin@example.com` / `change-me-now` — **შეცვალე!**). საცდელი გუნდი და დავალებები: `SEED_DEMO=true php artisan db:seed`.

## Laravel Cloud

1. დააკავშირე ეს რეპო ახალ აპლიკაციასთან, დაამატე მონაცემთა ბაზა (MySQL ან Postgres).
2. **Object storage bucket** დაამატე და `STUDIO_ASSETS_DISK` დააყენე იმ დისკის სახელზე — ლოკალური დისკი ყოველ deploy-ზე იშლება და ვიზუალები დაიკარგება.
3. Environment: `APP_LOCALE=ka`, `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `ADMIN_NAME`.
4. Deploy command: `php artisan migrate --force && php artisan db:seed --force` (seed უსაფრთხოა რამდენჯერაც გინდა — არსებულს არ ცვლის).
